# 2026-11-18 社交渠道开源项目核查

## 本轮完成

按所有者当前请求实际检索 GitHub，核查 20 个仓库的元数据、默认分支提交、README、许可证及部分接口源码，覆盖 QQ、微信、小红书、抖音、快手、Linux.do、NodeSeek、V2EX。结果与精简证据分别保存于 `docs/social-channel-research-20261118.md` 和 `docs/channel-research-evidence-20261118.json`，渠道摘要已更新。

QQ 的 LLBot 当前源码仍有私聊/群聊收发接口，适合优先做适配原型；Lagrange V2 有相关接口但许可证不明确。微信 OCR 项目可作为本地只读原型，不能承诺完整历史或稳定身份识别，必须移除其自主回复路径。小红书 MCP 有近期搜索/发布代码维护，适合读取试点，私信未证实。

排除过时或不匹配推荐：NapCatQQ 已留下结束声明，WeChatFerry 主仓库归档，wxauto 仍标注 3.9.x 且禁止商用/生产，MediaCrawler 明确禁止商业用途；F2 文档把搜索/评论标为未来实现。NodeSeek iOS 客户端、Linux.do 皮肤、V2EX 扩展都不能直接算服务器收发接口。具体证据和替代路线见报告。

## 验证与部署

本轮仅调研和持久化文档，没有安装/运行第三方项目、读取真实个人/群聊、调用测试发送或更改线上程序。新渠道状态均为待验证，未运行应用测试或重建镜像；文档/JSON 验证和 Git diff 检查用于本轮改动。

只读复查：公网 `/healthz` 200，staging，real_send_enabled=false；huoke Web/PostgreSQL healthy，worker/beat/Redis 容器运行。镜像仍为 `huoke:20261118-rate100`。服务器其他服务保留。

上一轮分析速率发布仍有效：100 次/滚动小时，每 36 秒调度一次，公开联系调查 5 位/小时；预算单次 $1、每日 $5、每月 $100。上一轮 105 项 PostgreSQL 测试、38 项定向测试、前端构建及自然调度观察是旧发布证据，不冒充本轮测试。发布记录与指标保留在 `.agent/state.json`。
