# 青鸟 AI 获客系统

确认来源：项目所有者 2026-10-27 的完整需求及补充。官网 https://bluebirdapi.com/ 仅允许查询，不允许修改配置、账号、渠道或业务数据。登录若需要接受条款，由用户确认后再操作。

## 产品事实

- 为国内开发者和企业提供统一模型 API 接口、按量计费；官网由所有者提供。
- 公开页面显示名称“青鸟 API”。网站的性能、部署地域、模型数量等宣传未经独立验证，不能转写成获客承诺。
- 模型清单、价格、折扣、服务保证、试用政策和具体适配需所有者确认。没有官方授权或客户案例证据，不得编造。

## 最小流程与架构

React + TypeScript 工作台；FastAPI 模块化后端；PostgreSQL 保存客户、来源、审核、拒收、持久化队列、成本及审计；Redis + Celery 调度。React 静态构建由 FastAPI 同域提供。初期不引入 Next.js SSR：工作台无需搜索引擎收录，单一镜像减少运维组件。

一个正式来源：HN 官方公开 API。它只验证读取、筛选、去重、客户档案，不代表已找到适合国内业务的有效客户。人工添加有证据的商务邮箱，所有者逐条核实。规则先筛选、可选模型再分析；当前无模型密钥时明确显示规则结果。基于确认事实生成简短草稿。所有者完整审核 → 批准 → 持久化队列 → 模拟或 SMTP。SMTP 适配器不代表 SMTP 已接通。

批准摘要绑定 lead_id、contact_id、recipient、channel、account、subject、body、attachments、version。审核请求携带界面看到的版本及摘要。编辑撤销批准。队列执行前重新验证；全局控制行锁保证并发下暂停、拒收、人工接管与发送互斥。发送尝试另按实际收件人/账号/内容去重，防止复制草稿重复发送。

持久化 sending 后再调用平台；崩溃、超时转 unknown 且禁止自动重试。当前没有 SMTP 状态查询 API，unknown 必须人工查询邮箱/供应商记录。SMTP DATA 接受显示 submitted，模拟显示 simulated，均不显示送达或已读。

## 验收与阶段

1. 阶段一：真实采集、客户档案、模型分析、可编辑草稿、完整人工审核、真实发送一个渠道。当前先完成隔离测试环境；没有 owner 批准不得发送真实客户消息。
2. 阶段二：IMAP/官方收件接口、转化事件、可靠性、备份/恢复、通知、费用统计。
3. 阶段三：以有效商机质量扩展国内开发者渠道、本地执行器、策略实验。

尚未实现：批量审核、附件、收件同步、自动回复、转化回传、留存/毛利、通知外发、本地浏览器执行器、自助产品资料配置。UI 必须如实展示未接通，不使用虚构统计。

## 成本及安全

用户月度 10,000 美元为最高允许值，不是消费目标。试运行配置单次分析 $1、每日 $5、每月 $100；扩大预算或购买服务须确认。没有模型价格则不调用。按保守 Token 上界预占预算，使用返回用量和配置价格估算；未返回用量保持未决预占，不能记录零费用。模型/提示/产品/内容版本纳入缓存键。

采集原文是不可信数据；纯文本展示；模型无工具权限；模型引用必须在原文中逐字存在。AI 不能产生发送授权。运维与所有者审核令牌分离。未知联系人、预算、职位、企业规模、采购意愿保持未知；不依据昵称跨平台合并。

费用账簿只覆盖获客模型运行，开发费用未知另记；客户模型 API 供给成本在计费平台独立核算。当前不能由采集数量推断效率、质量、转化率或毛利。
