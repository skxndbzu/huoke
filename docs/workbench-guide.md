# 工作台使用

入口：http://117.72.35.216:18080 。原有审核令牌继续有效。首次登录后进入“成本与配置 → 账号与密码”，设置自己的用户名和至少 12 位密码；以后直接使用账号登录。不会预设公共密码。

## 每天的操作

1. 打开“今日工作台”，从“待核实需求”进入客户。查看原文、AI 判断、未知事项和联系方式证据；有效或不匹配都填写判断理由。
2. 在“待首次联系”检查已核实需求。联系方式可以来自原文中公开商务邮箱，也可以有证据地添加微信、QQ、邮箱或联系页面；未验证地址不能直接发送邮件。
3. 生成并编辑招呼语，复制到你实际使用的客户端。复制不会发送，也不会授权系统发送。完成沟通后在客户页手工记录发生时间、渠道与内容。
4. 设置下次跟进时间，届时进入“到期跟进”；收到客户回复后记录为收到回复，并从“待处理回复”处理。拒绝、不匹配或结束会停止后续提醒。
5. 注册、首次调用、付费、持续使用等暂时手工记录实际业务事件。“效果统计”按客户去重计算；只修改阶段名称不会增加转化数字。

## 自动采集与模型

服务器每小时执行公开来源采集和最多 2 条新候选分析，不需要电脑常开。GitHub 已验证；V2EX 当前服务器网络受阻，渠道页显示真实失败原因。微信、QQ、邮件客户端收件尚未接通，需手动记录，不能当作实时统一收件箱。

在“渠道状态”调整关键词/排除条件、暂停来源或申请同步；一小时冷却限制可避免重复点击消耗请求。候选不等于有效商机，技术讨论也可能被初筛收录，需要人工标注。

在“成本与配置”添加或修改模型服务、模型名、密钥及估算单价。先保存，再验证模型列表，最后启用。修改后旧验证失效；已产生的异常模型调用不会自动重试。密钥不回显，不进入 Git。价格仅用于预算估算，实际账单以供应商为准。

真实自动发送仍关闭且队列暂停。原有逐条消息审核流程保留；本轮不会代你确认、发送或自动回复。当前 IP 为 HTTP，尚未配置 HTTPS。
